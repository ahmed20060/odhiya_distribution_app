# تطبيق توزيع الأضحية - شبراملس

هذا المشروع عبارة عن تطبيق Streamlit يساعد في إدارة وتوزيع الأضحية داخل قرية شبراملس. يمكنك من خلال التطبيق إضافة المستحقين وإضافة المندوبين وتقسيم المستحقين على المندوبين ومتابعة حالة التسليم لكل مستحق.

## كيفية التشغيل محليًا

1. تأكد من وجود Python 3.8 أو أحدث.
2. ثبت المتطلبات باستخدام:

    pip install -r requirements.txt

3. شغل التطبيق باستخدام:

    streamlit run app.py

4. افتح الرابط الذي يظهر في المتصفح واتبع التعليمات.

## الميزات

- إضافة مستحقين مع البيانات المطلوبة.
- إضافة مندوبين مع كود دخول لكل مندوب.
- توزيع تلقائي للمستحقين على المندوبين.
- شاشة خاصة لكل مندوب لمتابعة الحالات وتحديث حالة التسليم.
- عرض جميع المستحقين والمندوبين.
